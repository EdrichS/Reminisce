How To Use:

1. First access your Messages database on your Mac. This is usually found on the following directory: /Users/*username*/Library/Messages/chat.db

2. Then, in main.py, change the *TARGET_CHAT_IDENTIFIER* to the conversation you want to reminisce.

3. Then change the sender to your name and the else to the other person's name.

4. Lastly, run the program and enjoy your transcript!

This code is designed to be fully on Mac. This code is also designed only for individual conversations, so group chats do not work.
